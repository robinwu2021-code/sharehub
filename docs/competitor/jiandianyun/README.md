## 一、这家是谁

**简电 / 简电云 = 广州优匠科技有限公司**（[ujtek.cn](https://www.ujtek.cn/)，2017 成立）的共享充电 SaaS 品牌。
产品线**同时覆盖共享充电宝 + 两轮电瓶车 + 新能源汽车（OCPP 欧标/国标）**，面向运营商输出 SaaS——这与我们 [ADR-014 设备类型抽象](../../technical/ADR/) 的"充电宝/充电桩双业态"方向高度重合，是最贴近的对标对象。

软著佐证：「简电共享充电宝运营管理平台」V1.0（2024SR0433093，首发 2023-06-20）；「简电云 3.0 聚合充电公众号运营平台」（2026SR0226377）。
角色链：**运营商 → 代理商/地推 → 商户（门店） → C 端用户**。

## 三、采集说明（可复现 & 合规）

**运营端**（2026-07-29）
- 系统：`https://jdy-gocpp-dev.nat.ujtek.cn/platform/` — 简电云 **OCPP 充电运营管理平台** dev 环境
- 账号：用户本人持有的测试账号，**账号密码由用户本人在浏览器中输入**，未记录于本仓库、也未由 AI 代填
- 方式：在用户已登录的会话中，读取前端 AngularJS 作用域 `permissionMenu`（L2/L3 全量）与 `menuList`（L1 域）
- 校验：13 个 L1 域名称按节点 `id` 与 L2 的 `parent_id` 逐一比对确认，非推定
- 边界：**未做任何越权访问**，未调用未授权接口，未导出任何业务数据（仅菜单结构）

**C 端**（2026-07-13 历史会话采集，本次归档）
- 来源：墨刀原型「共享充电宝_全球版」，访问密码 `ujtek`（该密码为原型分享密码，非账号凭据）
- 方式：读取原型页面树（49 屏）

## 四、⚠️ 使用前必读的三条限制

1. **运营端那份是 OCPP 充电桩产品线**，不是共享充电宝线。业务对象是站场/桩/枪/车辆，**不能与我们的柜机/仓位/充电宝逐行等价映射**。可比的是经营结构（分成、财务、告警、设备台账），不可比的是业务名词层。
2. **菜单仅代表该账号角色的可见范围**（平台方角色、`包年`套餐）。更高权限或其他角色（代理端/商户端）可能另有菜单。公开资料宣称的"月卡/积分商城"等营销能力在此实例中不可见——**不等于产品没有**。
3. C 端那份是**充电宝线**的原型，与运营端那份**不是同一实例的两端**。

## 五、一句话结论

对方是**跑在生产上的多国部署充电运营系统**，强在告警规则引擎、发送治理、多支付渠道、按角色切分的财务视图、OCPI 漫游；弱在无工单闭环、无复式记账、无营销体系、权限模型单薄、无阿语/RTL。
我们功能矩阵更全更规范，但**多数仍是 mock 前端**——矩阵领先 ≠ 交付领先。详见 [03-对比分析 §四](03-对比分析.md)。
