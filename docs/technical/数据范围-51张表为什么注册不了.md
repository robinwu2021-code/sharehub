# 数据范围 · 那 51 张表为什么注册不了（2026-09-25 实验结论）

> 起因：`backend/known-unscoped-owned-tables.txt` 有 51 张表「带归属列、没登记数据范围」，
> 而台账头部写明未注册 = 全局放行、**漏注册不会报错只会静默泄露**。
> 本文记录一次动手前的实验：**它们不是没人做，是当前机制下做不了**。

---

## 一、先把关键前提验到底

`DataScopeRegistration` 的类注释声称 handler 是 **fail-closed**：
「当前 spec 的维度在本表锚点里找不到列」时生成 `1=0`（全部拒绝）而不是放行。

`DataScopeHandler` 在 neargo commons 里，**源码不在本仓**，读不了。所以用实验定：
给 `agt_commission`（只有 `agent_no`）临时只登记 `AGENT`，
让一个员工先按 ALL、再收敛到 SITE，数同一个列表。

| | ALL 范围 | 收敛到 SITE 之后 |
|---|---:|---:|
| **未注册**（基线） | 1 | **1** —— 不过滤 |
| **只登记 AGENT** | 2 | **0** |

⇒ **fail-closed 成立**，那句注释是真的。代价具体：
只登记 AGENT 的表，按站点收敛的员工**一行都看不到，而且不报错**。

> 基线那一栏是必要的。第一次跑探针时前提断言就挂了，
> 我差点当成「注册导致 ADMIN 也瞎了」—— 实际是 `agt_commission` 在测试库里是空表，
> 夹具建立在不存在的数据上。**没有基线的单向实验会把自己的夹具错误读成结论。**

## 二、于是 6 张代理表一张都不能登记

| 表 | 有的归属列 | 缺 |
|---|---|---|
| `agt_account` | agent_no | site_no · region_id |
| `agt_agent` | agent_no | site_no · region_id |
| `agt_agent_region` | agent_no · region_id | site_no |
| `agt_assignment` | agent_no | site_no · region_id |
| `agt_commission` | agent_no | site_no · region_id |
| `loc_site_agent` | site_no · agent_no | region_id |

**风险不是理论的**：库里现在就有 1 个 SITE 范围的员工（`iam_data_scope`：ALL×56、SITE×1）。
任何一张登记下去，那个人在对应页面上当场全瞎。

## 三、为什么补列也不对

第一批（V58）解决同类问题的办法是**把条件挪进列定义**——
给 `share_record` 加生成列 `agent_no = CASE WHEN payee_type='AGENT' THEN payee_no END`，
而不是改共享框架。那一手是对的，因为那张表**本来就承载着代理归属**，只是表达不出来。

本批不一样：缺的是 `site_no` / `region_id`，而**这些表在业务上就没有站点/区域归属**——
一条分润规则是「算给哪个代理商」，不是「属于哪个站点」。
给它编一个 `site_no` 等于**为了让机制通过而伪造业务语义**，
下一个人读到这一列会以为分润规则真有站点维度。

## 四、真正的选项（需要裁决，我不擅自选）

| | 做法 | 代价 |
|---|---|---|
| **A** | registry 支持「本表不适用某维度 → 该维度不过滤」 | 要改 neargo commons（共享框架，影响其它产品线）；且「不过滤」是放行，安全默认值从此变松 |
| **B** | 这些表不走 SQL 层，改在 service 层按 `agent_no` 显式过滤 | 回到「漏一处就泄露」的老问题，正是数据范围机制要消除的 |
| **C** | 维持现状 + 把「为什么不能注册」写进台账 | 缺口还在，但至少不再被误读成「没人做」 |
| **D** | 按访问主体缩小问题：这 6 张表**只有 ALL 与 AGENT 两类主体访问**，那就只登记 AGENT，并**同时禁止把 SITE/REGION 范围配给能访问这些页面的角色** | 把约束从表移到角色配置上，需要一条新卡口来守，否则又是静默失效 |

**我倾向 D**，理由：这 6 张是代理商档案，按站点或区域去切它本来就没有业务含义；
真正需要限制的只有「代理商只能看自己的」。但 D 必须配一条卡口——
「配了 SITE/REGION 范围的员工不得持有 `agent:*` 类权限码」——否则它会以最安静的方式失效。

## 五、本次没有做什么

- **没有注册任何一张表**。验清楚代价之后，硬注册等于给系统加一个静默失效点。
- 实验用的临时注册已回滚，`DataScopeRegistration` 与 HEAD 一致。
- 探针 `ScopeFailClosedProbeTest` 留下了（**不断言行为，只取证**），
  下次要重新判断时不必再搭一遍夹具。
