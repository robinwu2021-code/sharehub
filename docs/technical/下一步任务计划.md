## 竞品对标：简电云（2026-07-29 建档）

> 完整档案 **[docs/competitor/jiandianyun/](../competitor/jiandianyun/README.md)**：运营端 13 域/25 模块/**87 菜单项**真实菜单导出 + C 端 49 屏 IA + 三张差异表。
> ⚠️ 对方运营端是 **OCPP 充电桩线**（非充电宝线），只可比经营结构不可比业务名词。

对标得出的 5 条可执行建议（详见 [03-对比分析 §四](../competitor/jiandianyun/03-对比分析.md)）：

| 优先级 | 建议 | 一句话理由 |
|:---:|---|---|
| 1 | **补告警规则引擎**（告警码字典 + 通知规则）并接上工单开单 | 正好补齐 G6 的上游；做完我们"规则引擎+工单闭环"双全，对方只有前半 |
| 2 | **P1 补站点/设备经营明细** | 对方统计在订单域内 P1 可用，我们全压报表域(阶段2/3) → P1 运营看不到按站点数据 |
| 3 | **补 C 端申诉链路 + 运营端投诉订单** | 对方端到端闭环，我们只有 toast；商户纠纷取证必需 |
| 4 | **补短信/通知发送记录 + 拉黑** | OTP 短信是真钱，无记录不可追溯、无拉黑挡不住薅 |
| 5 | **结算单加按角色视图** | 借鉴对方"每个角色一眼看清自己的账"，成本低 |

**不跟进**：OCPI 漫游 / POS·Kiosk 终端 / 车辆·RFID（充电桩专属）；多 PSP 渠道抽象（过早抽象，等真出第二市场）。

### Task 3 — C端 profile 可写端点（C-ME）
**文件**：`backend/…/mp/web/UserMpController.java`

- `PATCH /mp/user/profile`：接收 `{nickname, email}`，更新 `usr_user`，返回最新 `UserProfileDto`
- `GET /mp/user/favorites` / `POST /mp/user/favorites/{siteNo}`：收藏表（`usr_favorite`，用户+siteNo 唯一，toggle 语义）
  - 建表 DDL：`CREATE TABLE usr_favorite (id BIGINT, c_user_no VARCHAR(32), site_no VARCHAR(32), created_at DATETIME, PRIMARY KEY(id), UNIQUE KEY uk_user_site(c_user_no, site_no))`

### Task 4 — 钱包端点（C-WA）
**文件**：`backend/…/mp/web/WalletMpController.java`

- `GET /mp/user/wallet` → 查 `usr_wallet`（balance/bonus/deposit/frozen/currency）
- `GET /mp/user/wallet/txns?page&size` → 查 `usr_wallet_txn`（type/title/amount/currency/at，分页）
- 建表 DDL：
  ```sql
  CREATE TABLE usr_wallet (id BIGINT, c_user_no VARCHAR(32) UNIQUE, balance DECIMAL(12,2), bonus DECIMAL(12,2), deposit DECIMAL(12,2), frozen DECIMAL(12,2), currency CHAR(3), PRIMARY KEY(id));
  CREATE TABLE usr_wallet_txn (id BIGINT, txn_no VARCHAR(32) UNIQUE, c_user_no VARCHAR(32), type VARCHAR(16), title VARCHAR(128), amount DECIMAL(12,2), currency CHAR(3), created_at DATETIME, PRIMARY KEY(id), KEY idx_user(c_user_no));
  ```

## 环境快速启动（接管者必读）

```bash
# 后端（JDK21，MariaDB pb_core 需启动）
cd backend
JAVA_HOME=<jdk21路径> mvn -pl powerbank-app spring-boot:run
# http://localhost:8080

# c-app（H5 开发）
cd c-app
cp .env .env.local          # 首次：复制 env 模板
# 编辑 .env.local：
#   VITE_USE_MOCK=true      # mock 模式（默认）
#   VITE_GMAPS_KEY=<key>    # Google Maps key（已在本地 .env.local，不入 git）
npm run dev:h5              # http://localhost:5174

# c-app（App，需 Android Studio + 模拟器）
npm run build:app && npx cap sync android
# Android Studio 打开 android/ 目录 → Run

# 运营端
cd ops-web
USE_MOCK=true npm run dev   # mock 模式
USE_MOCK=false npm run dev  # 联调后端（需后端运行）
# http://localhost:3000
```
