## 二、依赖与并行

```
S0 ─► S1 ─► S2 ─┬─► S3（认证）
                ├─► S4（库改名 + 任务）
                ├─► S5（网关）─┐
                └─► S6（支付）─┴─► S7（按摩椅）─► S8（充电桩）
```

- **S0 立即做**，不等任何评审；
- **S1 要早**：改名越晚越贵（今天订单百余条、前端与后端同仓同发）；它也是 S7 的前提；
- S3 / S4 / S5 / S6 在 S2 之后可以并行；**跨仓的只有 J1（ai-shop 任务服务）与 S6（ai-shop 支付服务）**，以及可选的 A1（`neargo-auth-store`，随框架 2.0），需与 ai-shop 的并行会话排期；
- S7 需要 S5（设备指令）与 S6（先付）都就绪。
