# 03 · 数据库

> 所属：[v4 详细规划](./README.md) · 命名：[01 §五](./01-通用设备与命名.md) · 现状真值：[db-schema-reference](../db-schema-reference.md)（脚本生成）· [业务模块分层](../业务模块分层.md)
> 约定沿用 [db-design](../db-design.md)：`id` 自增物理主键 + `<x>_no VARCHAR(36)` 业务唯一键 · 无物理外键 · 金额 `DECIMAL(18,2)` + `currency` ·
> 时间 `DATETIME(3)` · 通用列 `tenant_id` `created_at/by` `updated_at/by` `version` `deleted`

## 一、库划分（6 个库，一库一写入方）

| 库 | 写入方 | 内容 | 迁移脚本位置 | 隔离 |
|---|---|---|---|---|
| **`sharehub_core`** | sharehub-app | 全部业务表 + 基础设施表（`sys_outbox` `sys_event_consumed` `shedlock`） | `sharehub-app/…/db/core` | — |
| **`sharehub_auth`** | sharehub-app（认证模块） | 凭据、各端会话、登录日志、验证码、重置码 | `sharehub-auth/…/db/auth` | 独立 KMS；独立账号 |
| **`sharehub_pii`** | sharehub-app | 个人数据（姓名、证件、联系方式明文） | `sharehub-app/…/db/pii` | 独立 KMS · PDPL |
| ~~`sharehub_pay`~~ | — | **不再需要**：支付数据在共用支付服务自己的库里，按 `system=SHAREHUB` 隔离（[ADR-025](../ADR/ADR-025-直接复用ai-shop在跑的支付与任务服务-多系统改造.md)） | 共用服务自带 | 由共用服务保证 |
| **`sharehub_gw`** | sharehub-gateway | 厂商、绑定、指令、报文、心跳、固件 | `sharehub-gateway-kernel/…/db/gw` | 报文 / 心跳按月分区 |
| ~~`sharehub_job`~~ | — | **不再需要**：任务数据在共用任务服务自己的库里，按 `system=SHAREHUB` 隔离 | 共用服务自带 | 由共用服务保证 |

**规则**：

1. **一个库只有一个进程写**；其他进程要数据走接口或事件；
2. **跨库只存业务键 + 必要的快照列**（如工单存 `device_no` + `device_name` 快照），**不跨库 JOIN**；报表跨库部分走读模型；
3. **每个进程只跑自己库的迁移**，每个库一套 Flyway 历史表；
4. 应用内多数据源时：`sharehub_core` 为 `@Primary`，其余**不得** `@Primary`、注入必须 `@Qualifier`，
   且**不得注册 `Flyway` 类型的 bean**（否则主库迁移会静默不跑 —— ai-shop 踩过，[07 §六](./07-定时任务.md)）；
5. 起步：**同一个 MariaDB 实例分库**；出现扩容或合规信号再分实例（MENA 生产区域内独立实例）。

### 2.2 `sharehub_auth`

| 表 | 用途 |
|---|---|
| `cred_credential` | 员工 / 代理 / 消费者的密码凭据（bcrypt），失败计数与锁定 |
| `ops_session` · `ops_login_log` | 员工（STAFF）会话 / 登录日志 |
| `agt_session` · `agt_login_log` | 代理（AGENT）会话 / 登录日志 |
| `usr_session` · `usr_login_log` | 消费者（CONSUMER）会话 / 登录日志 |
| `auth_otp` | 验证码（只存哈希）、有效期、错误次数、锁定 |

会话与日志表结构照 ai-shop（`shop-auth-store`），**每个端一对，互不关联、不许 JOIN**（[06 §二](./06-认证与权限.md)）。

### 2.4 支付与任务的数据（在共用服务里，本项目无库）

[ADR-025](../ADR/ADR-025-直接复用ai-shop在跑的支付与任务服务-多系统改造.md) 起，ShareHub **不再建 `sharehub_pay` / `sharehub_job`**：

- **支付**：数据在共用支付服务自己的库里，每张表带 `system` 列，ShareHub 的行是 `system='SHAREHUB'`（[15 MP1 · MP4](./15-多系统多平台改造需求.md)）。
  ShareHub **不装配**积分（`pts_*`）、商户分账、商户结算单；业务关联走通用的 `biz_type` + `biz_no`（MP6），不用电商的 `order_no` / `entity_no`；
- **任务**：`job_definition` · `job_run` · `job_log` 同样带 `system` 列（MJ1–MJ2），ShareHub 只能看到并触发自己系统的任务（MJ5）；
- **ShareHub 侧仍需要的**：`shedlock` 表建在 `sharehub_core`（任务目标侧抢锁用），以及业务库里对支付流水号的**逻辑引用**（`pay_no`，不做外键）。

## 三、关键表结构

### 3.1 设备类型注册 `md_device_type`（🔁 加列）

```sql
ALTER TABLE md_device_type
  ADD COLUMN IF NOT EXISTS usage_mode VARCHAR(16) NOT NULL DEFAULT 'RENTAL' COMMENT 'RENTAL 借还 / SESSION 就地使用',
  ADD COLUMN IF NOT EXISTS pay_modes  JSON        NULL COMMENT '允许的付费模式，首个为默认：["PREAUTH","DEPOSIT"]',
  ADD COLUMN IF NOT EXISTS slot_kind  VARCHAR(16) NOT NULL DEFAULT 'BAY' COMMENT 'BAY 仓位 / CONNECTOR 枪 / SEAT 座位 / CELL 格口',
  MODIFY COLUMN default_metering VARCHAR(16) NOT NULL DEFAULT 'MINUTE' COMMENT 'MINUTE / KWH / PACKAGE / COUNT';

UPDATE md_device_type SET type_code = 'EV_CHARGER', command_family = 'EV_CHARGER',
       usage_mode = 'SESSION', slot_kind = 'CONNECTOR', pay_modes = '["PREAUTH"]' WHERE type_code = 'EV_PILE';
UPDATE md_device_type SET usage_mode = 'RENTAL', slot_kind = 'BAY', pay_modes = '["PREAUTH","DEPOSIT","CREDIT"]'
 WHERE type_code = 'POWERBANK';
UPDATE md_device_type SET usage_mode = 'SESSION', slot_kind = 'CELL', pay_modes = '["PREPAY","PREAUTH"]'
 WHERE type_code = 'LOCKER';

INSERT INTO md_device_type (type_code, name_zh, name_en, name_ar, has_movable_item, item_table, order_ext_table,
       default_metering, reservation_target, supports_return_elsewhere, command_family, usage_mode, pay_modes, slot_kind)
VALUES ('MASSAGE_CHAIR', '按摩椅', 'Massage Chair', 'كرسي تدليك', 0, NULL, 'ord_session_ext',
        'PACKAGE', 'SLOT', 0, 'SESSION', 'SESSION', '["PREPAY"]', 'SEAT')
ON DUPLICATE KEY UPDATE type_code = type_code;
```

### 3.5 功能点权限模型（🆕，照 ai-shop 的「功能 → 功能点 → 角色 → 成员」）

```sql
CREATE TABLE iam_function (            -- 菜单分区（一级 / 二级）
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  function_code VARCHAR(64) NOT NULL, parent_code VARCHAR(64) NULL,
  realm VARCHAR(16) NOT NULL DEFAULT 'STAFF' COMMENT 'STAFF / AGENT：代理端菜单独立一棵',
  name VARCHAR(64) NOT NULL, name_en VARCHAR(64) NULL, name_ar VARCHAR(64) NULL,
  icon VARCHAR(64) NULL, href VARCHAR(128) NULL, sort INT NOT NULL DEFAULT 0,
  status VARCHAR(16) NOT NULL DEFAULT 'ENABLED', created_at DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  updated_at DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  UNIQUE KEY uk_function_code (function_code)
) COMMENT '功能（菜单分区）';

CREATE TABLE iam_function_point (      -- 功能点：一个页面（MENU）或一个操作（ACTION）
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  point_code VARCHAR(96) NOT NULL, function_code VARCHAR(64) NOT NULL,
  point_type VARCHAR(8) NOT NULL COMMENT 'MENU / ACTION',
  name VARCHAR(64) NOT NULL, name_en VARCHAR(64) NULL, name_ar VARCHAR(64) NULL,
  href VARCHAR(128) NULL COMMENT 'MENU 的前端路由',
  perm_code VARCHAR(96) NULL COMMENT '后端权限码（@perm.can）；NULL = 不受权限约束',
  backend_status VARCHAR(16) NOT NULL DEFAULT 'IMPLEMENTED' COMMENT 'IMPLEMENTED / NOT_IMPLEMENTED：未实现的前端置灰',
  phase TINYINT NULL COMMENT '产品分期徽章', sort INT NOT NULL DEFAULT 0,
  UNIQUE KEY uk_point_code (point_code), KEY idx_point_function (function_code)
) COMMENT '功能点 —— 前后端共用一套码，不做 UI 码 / 后端码双层映射';

ALTER TABLE iam_role ADD COLUMN IF NOT EXISTS wildcard TINYINT(1) NOT NULL DEFAULT 0 COMMENT '超管：权限解析短路为 *';
CREATE TABLE iam_role_point  (role_no VARCHAR(36) NOT NULL, point_code VARCHAR(96) NOT NULL,
                              PRIMARY KEY (role_no, point_code)) COMMENT '角色 × 功能点';
CREATE TABLE iam_role_member (realm VARCHAR(16) NOT NULL, subject_no VARCHAR(36) NOT NULL, role_no VARCHAR(36) NOT NULL,
                              created_at DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
                              PRIMARY KEY (realm, subject_no, role_no)) COMMENT '人员 × 角色（一人多角色）';
```

数据迁移：`iam_menu` → `iam_function` + MENU 功能点；`iam_permission` + `iam_role_perm` → ACTION 功能点 + `iam_role_point`；
`iam_employee_role` → `iam_role_member(realm='STAFF')`。

### 3.7 认证库（🆕，照 ai-shop 会话表 + ShareHub 的凭据隔离）

```sql
-- 三端各一对，结构相同，以 ops_ 为例（agt_ / usr_ 同构）
CREATE TABLE ops_session (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  token_hash    CHAR(64)    NOT NULL COMMENT 'SHA-256(令牌)，不存明文',
  subject_no    VARCHAR(36) NOT NULL COMMENT 'employee_no / account_no / c_user_no',
  issued_at     DATETIME(3) NOT NULL, expires_at DATETIME(3) NOT NULL COMMENT '滑动续期：使用时顺延',
  last_seen_at  DATETIME(3) NULL,
  revoked_at    DATETIME(3) NULL,   revoke_reason VARCHAR(16) NULL COMMENT 'LOGOUT / DISABLED / PASSWORD_CHANGED / FORCED_OUT',
  client_type   VARCHAR(16) NULL COMMENT 'WEB / APP / MINI / H5',
  UNIQUE KEY uk_ops_session_token (token_hash), KEY idx_ops_session_subject (subject_no), KEY idx_ops_session_revoked (revoked_at)
) COMMENT '员工会话 —— 只存「他是谁」，权限与身份每次请求现算';

CREATE TABLE ops_login_log (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, at DATETIME(3) NOT NULL,
  event VARCHAR(16) NOT NULL COMMENT 'LOGIN / LOGOUT / LOGIN_FAILED / REVOKED', subject_no VARCHAR(36) NULL,
  principal_masked VARCHAR(64) NULL, success TINYINT(1) NOT NULL, reason VARCHAR(32) NULL,
  client_ip VARCHAR(45) NULL, user_agent VARCHAR(256) NULL, KEY idx_ops_login_at (at)
);

CREATE TABLE cred_credential (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  realm VARCHAR(16) NOT NULL, subject_no VARCHAR(36) NOT NULL, cred_type VARCHAR(16) NOT NULL DEFAULT 'PASSWORD',
  secret_hash VARCHAR(100) NOT NULL COMMENT 'bcrypt(cost=10)',
  must_change TINYINT(1) NOT NULL DEFAULT 0, failed_count INT NOT NULL DEFAULT 0, locked_until DATETIME(3) NULL,
  updated_at DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  UNIQUE KEY uk_cred (realm, subject_no, cred_type)
);

CREATE TABLE auth_otp (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  target_hash CHAR(64) NOT NULL COMMENT 'SHA-256(手机号/邮箱)', scene VARCHAR(16) NOT NULL COMMENT 'LOGIN / BIND / RESET',
  code_hash CHAR(64) NOT NULL, expires_at DATETIME(3) NOT NULL, attempts INT NOT NULL DEFAULT 0,
  consumed_at DATETIME(3) NULL, client_ip VARCHAR(45) NULL, created_at DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  KEY idx_otp_target (target_hash, scene, created_at)
) COMMENT '验证码落库（ai-shop 放内存导致只能单实例，这里改库）；发送频控按本表计数';
```

## 四、数据范围注册（行级）

`DataScopeRegistration` 登记「表 → 锚点列」，改名后同步：
