## 七、贯穿全程的纪律

| 项 | 要求 |
|---|---|
| 负对照 | 每条规则、每个状态机、每道闸：拆掉 → 对应用例红，恢复 → 绿 |
| 既有测试 | 接入时**一条不改**仍全绿（AC-1） |
| 权限码 | 用之前先确认在真源表中存在 |
| 并发提交 | 逐文件 `git diff` 确认；不 `git add -A` |
| 迁移号 | 共享分支上先看最新号，避免撞号 |
| 旧表 | 一律保留只读，不物理删除 |
