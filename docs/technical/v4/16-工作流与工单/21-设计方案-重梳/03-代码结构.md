## 三、模块内分层（四个能力模块相同）

| 层 | 放什么 | 规则 |
|---|---|---|
| `web` | 控制器；只做 DTO 映射与取 `Actor` | 不写业务逻辑 |
| `app` | 应用服务（用例）；**事务边界** | 一个公开方法 = 一个事务；声明所需产品权限 |
| `domain` | 聚合 · 值对象 · 领域服务 | 不依赖 Spring、JDBC；纯单元测试 |
| `port` | 仓储与外部能力的接口 | domain 只依赖 port |
| `infra` / `timer` / `store` | port 的实现、定时任务、DAO | SQL 只出现在 `*-store` |

## 四、关键类（引擎部分）

| 类 | 职责 | 流程（02 §八） |
|---|---|---|
| `ProcessValidator` | 结构 · 门 · 引用 · 可枚举性校验；**一次返回全部错误** | 6.3 |
| `CompiledProcess` | 编译后结构：`(from, code) → Transition` · 状态 → 类别 / 门；按定义行 + 版本缓存 | 8.1 |
| `Transitioner` | 迁移的纯领域判断（边 · who · when · requires · 门收尾 / 启动 · SLA 动作）；不做 IO | 8.1 |
| `InstanceAppService.transition` | 事务编排：读 → 判断 → 条件更新 → 日志 → 门 → 动作 → SLA → 事件 | 8.1 |
| `CandidateKeys` | Actor → 候选键集合；待办查询与办理校验共用 | 8.2 |
| `Planner` · `ApprovalRules` | 求本轮 plan；五条规则固定顺序，各一个错误键 | 8.3 |
| `ExternalGateRunner` | 生成一次性令牌、发事件、处理回复（条件更新作废令牌） | 8.4 |
| `TargetMatcher` · `DueCalculator` | SLA 目标匹配；自然 / 工作时间到期推算，暂停顺延 | 8.5 |
| `RoundRobinPolicy` | 组内游标条件更新（防并发重复分配） | 7.1 |
| `ScopeDeriver` | 类型的 `scopeFrom` × 字段值 → 范围标签 | 7.2 |
| `ActorResolver` | 三类调用方 → `Actor`（令牌声明 ∪ 目录） | 5.2 |
| `DbSchedulerTimerScheduler` | 全进程共用的定时适配；任务不带数据 | 九 |
