## 八、贯穿全程的纪律

| 项 | 要求 |
|---|---|
| 负对照 | 每条保护（隔离 · 可见性 · 规则 · 并发 · 幂等）配一个「拆掉即变红」的用例，同文件放 |
| 三库 | 集成测试在 MySQL 与 PostgreSQL 上各跑；H2 只做快速档，不作为通过依据 |
| 无特例 | 代码与定义里不出现任何客户名（A9）；接入方的诉求先对照附录 A，覆盖不了先问「是否所有运营系统都需要」 |
| 契约 | OpenAPI 落盘入库，CI 比对；破坏性变更起 `/v2` |
| 日志 | 带业务键与 `traceId` / `workspace` / `actor`；不打令牌、凭证、联系方式 |
| 提交 | 只用显式路径提交；动手前 `git status` 确认没有他人在途改动 |
