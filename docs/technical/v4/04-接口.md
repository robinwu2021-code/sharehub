## 一、接入面（路径前缀）

| 前缀 | 面向 | 服务进程 | 鉴权 | 变化 |
|---|---|---|---|---|
| `/api/{auth,ops,trade,user,agent,platform}/**` | 运营端 ops-web（含代理视图） | sharehub-app | 员工 / 代理令牌 + 权限码 + 数据范围 | 6 个前缀**不得新增** |
| `/mp/**` | C 端 c-app（App / 小程序 / H5） | sharehub-app | 消费者令牌 + 属主校验 | 见 §四 |
| `/internal/**` | 进程之间 | 各进程 | 服务凭证 `X-Internal-Token` / 任务令牌 `X-Job-Token` | nginx 外网封死；**浏览器不得直接调**（见 §三 ⚠️） |
| `/gw/**` | 厂商云 Webhook | sharehub-gateway | 厂商签名 | 从 app 移到 gateway |
| `/ocpp/**` | 充电桩（WebSocket） | sharehub-gateway | 桩的 Basic Auth / TLS 证书 | 🆕 |
| `/pay/callback/**` | 支付通道回调 | pay-svc | 通道签名 | 🆕，取代 `/notify/**` |
| `/openapi/**` | 第三方 / 互联互通伙伴 | sharehub-app | AppKey 签名 + 限流 | 预留 |

控制器放在各业务域的 `api.{ops,mp,internal}` 子包（照 ai-shop；拆服务时随域走），只有跨域编排（报表、看板）放 `sharehub-app` 的 `portal`（[09 §四](./09-后端代码架构.md)）。

## 二、设计规则

### 2.1 通用命名

1. **资源名用通用词**（[01 §5.2](./01-通用设备与命名.md)）：`devices` · `slots` · `orders` · `device-types` · `vendors` · `commands`；
   类型专属资源只有登记过的几个（`powerbanks` · `buyout`）；
2. **按设备类型区分靠参数，不靠路径**：`GET /api/ops/devices?deviceType=EV_CHARGER`，**不要** `/api/ops/ev-chargers`；
3. **类型专属字段放在以形态命名的子对象里**：订单的 `rental` / `charging` / `session` / `locker`，设备的 `powerbank` 统计等 ——
   通用字段永远在顶层，端上按 `deviceType` 决定渲染哪块；
4. 路径 kebab-case 复数名词；字段 camelCase；业务号 `xxxNo`；时间 `xxxAt`（`yyyy-MM-dd HH:mm:ss`）；枚举大写下划线；
5. 动作用子资源动词：`/orders/{no}/stop` · `/devices/{no}/commands` · `/jobs/{name}/trigger`；
6. **契约禁止 `delete*`**：软删除用 `archive` / `unarchive`（沿用）。

### 2.2 通用约定

| 项 | 约定 |
|---|---|
| 出参 | `Result{code, message, data}`，`code=0` 成功；分页 `PageResult{list, total}` |
| 入参分页 | `page`（从 1 起）· `size`（默认 10，上限 200） |
| 幂等 | 所有创建类写接口接受 `Idempotency-Key` 头（或体内 `idempotencyKey`），同键重复请求返回同一结果 |
| 语言 | `Accept-Language: zh / en / ar`，错误文案按它返回 |
| 金额 | 两位小数数字 + 独立 `currency`（`AED` …），不用浮点计算 |
| 追踪 | 入站生成 / 透传 `traceparent`，出参头回写 `X-Trace-Id` |

### 2.3 错误码（认证类照 ai-shop，**同时**使用真实 HTTP 状态）

| HTTP | `code` | 含义 | 端上处理 |
|---|---|---|---|
| 401 | `10401` | 未登录（没带令牌 / 前缀不符） | 去登录 |
| 401 | `10402` | 会话失效（过期 / 登出 / 被踢 / 改密） | 清本地会话；小程序先静默登录重试一次 |
| 403 | `10403` | 无权限（`@perm.can` 拒绝） | 提示 + 重新拉权限 |
| 404 | `10404` | 资源不存在 —— **数据范围外、非本人资源也返回它**（不暴露资源是否存在） | 提示 |
| 409 | `10409` | 冲突（手机号已被占用、状态不允许） | 提示 |
| 429 | `10429` | 频率超限（登录 / 验证码） | 提示剩余等待秒数 |
| 400 | `10450` `10451` `10454` `10455` | 验证码：发送太频繁 / 当日超限 / 输错锁定 / 错误或过期 | |
| 400 | `10456` `10457` `10458` | 密码：错误 / 未设置 / 账号锁定 | |

通用段 `10400` `10401` `10402` `10403` `10404` `10409` `10429` `10500` 与 ai-shop `ErrorCode` 同码同义。**与 ai-shop 的一处不同**：ai-shop 权限拒绝返回 HTTP 200 + `10403`，导致它的运营端判 `status === 403` 的逻辑从未触发；
ShareHub **HTTP 状态与业务码同时给**，端上两者任一命中即按上表处理。业务错误码按 ai-shop 的分段骨架（[09 §5.1](./09-后端代码架构.md)）。

```json
  "deviceNo": "DV2609010000321", "slotIndex": 1, "siteNo": "ST0012", "siteName": "Dubai Mall L2",
  "status": "ACTIVE", "subStatus": null,
  "startedAt": "2026-09-23 12:00:05", "endedAt": null,
  "amount": 10.00, "currency": "AED", "paidAmount": 10.00, "depositAmount": 0.00,
  "priceSnapshot": { "planNo": "PP0003", "items": [{ "code": "M10", "name": "10 min", "price": 10.00 }] },
  "rental":   null,
  "charging": null,
  "session":  { "packageCode": "M10", "plannedSec": 600, "extendedSec": 0, "actualSec": null, "program": "RELAX", "stopReason": null },
  "locker":   null
}
```

充电宝单则 `"usageMode": "RENTAL"`、`"payMode": "PREAUTH"`，`rental` 为
`{ "powerbankNo": "PB…", "returnDeviceNo": null, "returnSlotIndex": null, "buyout": false, "durationMin": 42 }`，其余子对象为 `null`。

### 4.3 通用建单

```http
POST /mp/trade/orders
Idempotency-Key: 5f0c…

{ "deviceNo": "DV2609010000321", "slotIndex": null, "packageCode": "M10", "payMode": "PREPAY", "couponNo": null }
```

```json
{ "orderNo": "OD…", "status": "CREATED", "subStatus": "PAYING",
  "nextAction": { "type": "PAY", "cashier": { "channel": "NGENIUS", "params": { … } } } }
```

| `nextAction.type` | 含义 | 端上 |
|---|---|---|
| `PREAUTH` | 需完成预授权（充电宝 / 充电桩） | 拉起支付 SDK，完成后轮询订单 |
| `PAY` | 需先付款（按摩椅 / 储物柜） | 拉起支付 SDK，完成后轮询订单 |
| `WAIT_DEVICE` | 支付已就绪，等设备执行（弹仓 / 启动 / 开门） | 展示「设备处理中」，轮询订单 |
| `NONE` | 已开始（信用免押且设备已回执） | 进入使用中页 |

`slotIndex` 为空时由类型模块选槽（充电宝选电量最高的仓、按摩椅就是 1 号座）；`packageCode` 只对套餐计费有意义；
`payMode` 为空取该类型默认值。服务端校验：该类型是否允许该 `payMode`、用户是否有进行中订单、风控。

## 七、南向与回调

| 端点 | 进程 | 说明 |
|---|---|---|
| `POST /gw/callback/{vendorCode}` | gateway | 厂商云 Webhook：验签 → 驱动解析 → 归一化事件 → 落报文 → 回 2xx |
| `GET /ocpp/{chargePointId}`（WebSocket 升级，子协议 `ocpp1.6` / `ocpp2.0.1`） | gateway | 充电桩长连接 |
| TCP 端口（按厂商分配） · MQTT（EMQX） | gateway | 设备直连，见 [05 网关 §三](./05-网关.md) |
| `POST /pay/callback/{channel}` · `/pay/callback/{channel}/refund` | pay-svc | 通道回调：验签 → 回查 → 落库 → 发事件；回查失败返回 FAIL 让通道重推 |
