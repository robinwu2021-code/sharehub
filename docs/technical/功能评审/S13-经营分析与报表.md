## 〇、阶段结论

## 二、跨功能问题

### 2.1 `JdbcTemplate` 直查不受数据范围约束

数据范围只挂在 MyBatis-Plus 拦截器上（`DataScopeHandler.java:13-15`）。`DataScopeRegistration` 的类注释与 `ReportMappers` 的类注释都说「自写 SQL 一视同仁、自动生效」——**对 `@Select` 成立，对 `JdbcTemplate` 不成立**，而代码里没有任何地方写明后者。主代码有 49 个类注入 `JdbcTemplate`，多数是写路径、取号或任务（无会话，本就全域）；本阶段确认会被受限主体触达的读路径是 `OpsFlowMetricsService`（P0-1）。`AgentPerformanceServiceImpl.assignments`、`LeadServiceImpl`、`LocService` 等读路径需逐个过一遍（S0 统一）。

**方案**：新棘轮台账 `known-jdbc-read-paths.txt`——扫描「被 `@PreAuthorize` 端点调用、且注入 `JdbcTemplate` 执行 `SELECT`」的服务，冻结现状只准变短；每个条目要么改 MyBatis，要么在方法上声明「全域主体专用」并在入口判 `DataScopeContext.current().all()`。并修正两处类注释。本阶段只修 P0-1；全仓扫描在 S0 落地（OPT-S13-21）。

### 2.2 「端点先通、口径后填」（本阶段 5 处）

有端点、有权限、有菜单，但没有数据源或恒为常量：`/api/agent/performance` 恒空页（`AgentPerformanceServiceImpl.java:45-48`）；员工绩效表 `iam_staff_perf` 全仓只有建表与查询、**没有写入方**（`V5__v2_platform_system.sql:36` · `StaffPerformanceServiceImpl.java:42`）；回本天数恒 0；「应结算」在开发库恒 0（`ReportMappers.java:168-173` 注释已说明）；运维考核以「仅展示」列作键。这与「页面能配、计算不读」是同一族问题：**界面显示得像真的**。

**规则**：未实现的读端点返回 501 `error.common.not_implemented`，不返回空页；恒为常量的字段从出参删除或改 `null`（前端显示「—」）并在报表定义里写明「不可得」原因。员工绩效的写入方归 S0 / 组织域（二期），本阶段只要求返回 501。

### 2.3 同一指标多处各算

GMV：报表域（`fee_amount`、借出日、不分状态）与运营总览（`amount`、归还日、`amount > 0`）两套；在线率：看板 / 大屏、运营总览（同口径）与运维考核（不排除 FAULT）。S1 OPT-S1-17 的商家经营汇总、S8 VAT 台账、S11 应付又都会各自统计金额。

**方案**：`report.metric` 包提供 `MetricCatalog`——每个指标一个定义（SQL 片段、单位、口径文本、适用报表），看板、报表、经营汇总、导出都引用；ArchUnit 卡口：`report` 包外不得出现 `SUM(o.amount)` / `SUM(o.fee_amount)` 字面量（OPT-S13-02）。

### 2.4 业务时区：运行期可改 vs 启动时定格

见 SF-RPT-02 代码结构。这与 S0 §2.7（存储时区混用）是同一主题的另一面：S0 管「存的是哪个时区」，这里管「按哪个时区切日」。**规则**：业务时区只有一个来源；SQL 切日与服务层「今天」必须同源；多市场时按市场分区计算，不用全局偏移（OPT-S13-11）。

### 2.5 按名字而非编号聚合

报表事实、机柜快照、合约费率三处都按站点名关联（`ReportMappers.java:62, 128, 156`），根因是 `loc_contract.site_no` 未回填、`ord_order.site_no` 历史单为空。按名字聚合会把同名站点合并、把改名站点拆开，也让按站点的数据范围失效（SITE 维度锚点是编号）。**方案**：回填两列（与 S3 对齐），聚合键一律编号（OPT-S13-06）。

1. **P0-1 实测**：以 AGENT 会话（如 `AG002`）与 ADMIN 会话分别调 `GET /api/ops/ops-flow-metrics?from=2026-01-01&to=2026-10-28`，`leadsCreated`、`contractsEnded`、`woWithSla` 两者相同即确认越权；静态确认：`OpsFlowMetricsService` 只注入 `JdbcTemplate`（`:41-45`），`DataScopeHandler` 实现的是 MyBatis-Plus `MultiDataPermissionHandler`（`:3, 20`）。
