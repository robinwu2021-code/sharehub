## 〇、阶段结论

售后这一段的**单据骨架**是对的：退款申请与审批分离、申请幂等键必填且服务端不自补、驳回必填原因、审批人服务端回填；押金买断与解冻已从客服码收回到财务码并有用例（`DepositPermissionTest`）；催缴确实「只留痕不改状态」；干预记录 append-only。

AND status='IN_USE' AND version=?`，影响行数必须为 1（否则 409 且不写任何东西）→ 插 `ord_max_charge(pay_status=PENDING)` → 插 `pay_order(INIT, request_no=MAXCHARGE-<orderNo>)`（OPT-S6-16）→ 流水 `MAX_CHARGE`（操作人 system）→ 事务内发布 `MaxChargeTriggered`（Outbox，S0 OPT-S0-22）。提交后由请款执行器以同一 `request_no` 请款；结果回写 `ord_max_charge.pay_status` 与 `ord_order.pay_status`；明确失败转 SF-SAL-05 的欠费台账。

- **之后归还**：写 `ord_order.returned_at` 与 `ord_max_charge.returned_at / return_cabinet_no`，金额与支付记录不动（RQ-BIL-04）；流水与运营待办随 OPT-S6-24。

### 2.3 售后资金动作收敛为一张资金售后单

今天「把钱还给用户 / 少收用户的钱」有 7 个入口、4 种实现（其中 5 个不动钱）：运营端退款申请、客服报障转退款、C 端报障自动转退款、干预转退款、干预免单、干预补偿、投诉结案退款 / 补偿、异常处置退款。**方案**：以 `ord_refund` 为唯一的「资金售后单」，`kind` 区分动作语义，`source + source_ref` 去重，共用同一审批与执行器：

| `kind` | 适用订单 | 审批通过后的资金动作 | 会计方向 |
|---|---|---|---|
| `REFUND` | 已收款 | 原路退款（执行器出款），累计 ≤ 实收 | 冲减收入 |
| `WAIVE` | 未收款（进行中 / 已归还未结 / 欠费） | 减少应收：进行中单在结算链加一项人工减免；欠费单条件更新应收并在为 0 时结清欠费台账；**已收款单自动转 `REFUND`** | 冲减收入 |
| `COMPENSATE` | 任意 | 去向待裁决（§二.7）：原路 / 钱包 / 券 | 费用 |
| `WRITE_OFF` | 欠费 `EXHAUSTED` | 关闭欠费台账，解除借出拦截与否待定 | 坏账 |

`source` 与来源键：`OPS(idempotencyKey)` · `CS_TICKET(ticketNo)` · `C_REPORT(orderNo)` · `COMPLAINT(complaintNo)` · `EXCEPTION(exceptionNo)` · `INTERVENTION(interventionNo)`。同一来源键重复提交返回已有单；不同来源对同一订单的金额由「可退余额预留」统一约束。审批权限沿用 `order:refund:audit`（财务）；是否分额度两级审批待裁决（`功能权限清单.md:402` 已列为待定）。

### 2.7 需运营方裁决（给选项与代价，不替运营方选）

**① 补偿的去向**（OPT-S7-14）

| 选项 | 含义 | 代价 |
|---|---|---|
| A 原路退款 | 补偿 = 一笔额外退款 | 受「累计 ≤ 实收」约束，0 元单无法补偿；最简单 |
| B 入钱包余额 | 补至 C 端余额 | 钱包（SF-CON-04）是二期；余额是负债，需财务口径 |
| C 发券 | 补偿为优惠券 | 营销（SF-SAL-12）二期；不是现金，投诉人可能不接受 |

**② 减免与补偿的审批门槛**（RQ-SEC-03 要求「退款、核销、财务调整须审批」）

| 选项 | 代价 |
|---|---|
| A 一律审批 | 合规最清楚；客服现场处置变慢，财务待办量上升 |
| B 单笔 ≤ X 且当日累计 ≤ Y 免审，超出审批 | 需要额度配置与按人累计；须向审计说明阈值来源 |
| C 免单免审、补偿审批 | 免单只少收不付出，风险较低；但「全额免单」与「全额退款」对收入的影响相同 |

**③ 大额退款是否二级审批**（`功能权限清单.md:402` 已列待定）：A 否；B 超过阈值需第二位财务复核（`ord_refund` 加 `second_auditor_no`）。

**④ 坏账核销**（OPT-S7-08）：重试用尽后是否允许核销、核销后是否解除借出拦截、核销审批人。

**⑤ K4 / K5**：见 S6 §二.4。本阶段与裁决无关、先做：OPT-S7-01（记录、分列、事件、条件迁移）、OPT-S7-02（任务可观测与频率）、OPT-S7-03（查询端点按金额口径）；裁决后做：OPT-S7-04。
