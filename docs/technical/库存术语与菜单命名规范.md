# 库存术语与菜单命名规范

> 2026-10-30 · 适用于现行功能规格、运营端菜单及业务文案。原始需求引文、已执行迁移和历史版本保留当时名称；内部路由、API字段、枚举和文件名不作为产品术语。

## 一 命名原则

菜单命名按业务对象和作业命名；库存数量、业务单据、设备交付和设备生命周期分别表达。页面展示设备列表就不命名为单据列表。当前系统管理设备和物料库存，不具备完整采购销售业务时仍称库存管理，不因通用库存服务承载而统一叫进销存。

## 二 统一术语

| 概念 | 现行名称 | 使用边界 |
|---|---|---|
| 库存模块 | 库存管理 | 仓内数量、入出库、盘点和库存账 |
| 采购业务凭证 | 采购单 | 订购数量、供应商、价格、交期与采购状态 |
| 实物到货确认 | 收货 | 分批实收，独立于质检与可用数量 |
| 到货检查 | 入库检验／质检 | 待检、合格、不合格与放行凭证 |
| 入库业务凭证 | 入库单 | 收货、期初、退库等来源形成的入库记录 |
| 出库作业及设备交付页面 | 出库管理 | 当前 /inventory?tab=issued；按商家展示交付与安装状态 |
| 出库业务凭证 | 出库单 | 具有单号、明细、来源仓、商家、经办人、时间和过账状态的库存单据；不能指整个已出库设备集合 |
| 原出库池／出库候选池 | 待安装设备 | 安装流程选项：按商家筛选已出库、符合签收及绑定阶段的设备 |
| 跨状态查询集合 | 已出库设备 | 包含待签收、待绑定、待安装、已上线等状态；不能全体称待安装 |
| 设备交付确认 | 签收 | 接收人、时间及差异；安装验收不是再次签收扣库存 |
| 设备与点位关联 | 绑定点位 | 系统动作，不代替现场安装；可保留待绑定这一细分状态 |
| 设备仓内移动凭证 | 调拨单 | 源仓、目标仓、发出、在途、实收和差异 |
| 已收设备回仓 | 退库 | 须确认实收；回仓待检与可用库存分列 |
| 供应商退货 | 采购退货 | 当前界面“退供应商”的业务用途，不与商家退库混淆 |
| 无法使用的在库资产退出 | 报废出库 | 当前处置出库页面的用途；同页另有采购退货，保留用途区分 |
| 实物核查业务凭证 | 盘点单 | 账面快照、实盘、差异、审核及调整 |
| 数量差异 | 盘盈／盘亏 | 属盘点结果；运输短少和多收属于收货／签收差异 |
| 库存更正凭证 | 库存调整单／反向单据 | 受控更正，不直接覆盖历史余额或移动 |
| 当前数量 | 库存余额 | 实物、待检、不可用、可用数量分列；采购未收不计仓内余额 |
| 数量变化事件 | 库存流水 | 关联业务单据；不能用设备在线变化冒充库存变化 |
| 已订购未到货 | 采购未收 | 不与仓间调拨在途合并为同一数量 |
| 仓间运输 | 调拨在途 | 已发出、目标仓未实收的仓间移动 |
| 保养与故障修复 | 维护／维修 | 现场维修、回仓维修、返厂维修分别跟踪 |
| 全部资产的历史 | 设备履历 | 安装、迁点、故障、维修、撤机、交付等关联历史；仓外事件不重复改库存 |

## 三 现行菜单review结论

保留库存管理的主数据、出入库、库内作业、库存账、设置五组。物料档案、仓库、供应商、入库单、物料单据、库存调拨、盘点、资产差异、库存余额、物料库存、库存流水和库存设置可保留；“资产差异”覆盖运输与撤机清点，不窄化为盘点差异。“处置出库”保留为聚合页，页内用途应明确报废出库和采购退货。

将 /inventory?tab=issued 菜单由出库单调整为出库管理；导航、面包屑、翻译、数据库菜单迁移同步。已执行V210保留，新增V211更名；部署迁移后数据库驱动菜单才使用新名称。

安装入口使用待安装设备；跨状态查询使用已出库设备。中文产品文案不再使用池、候选池作为业务名称。保留 issued/pool/RETURN_TO_POOL 等兼容标识，不改变其协议。

## 四 商家出库规则

出库必须选择商家；安装按商家筛选待安装设备。待签收、未出库、其他商家、已退库、故障、报废设备不可选作新安装设备。已绑定待安装与已安装待上线分别处理。出库交付记录可追溯，上线不重复扣库存。

本次是术语和菜单展示调整，不等于此前确认的安装入口与服务端候选校验已开发完成。
