ShareHub 领域模型

一个运营商、多个品牌、若干代理商，在别人的场地上放设备。三张图：谁指向谁，谁是谁的一种，谁的行为离不开谁。

  • 商户禁用词
  • 加盟商 / 代理商 / 城市合伙人→代理商 Agent
  • 门店 / 站点→站点 Site
  • 租户不存在（ADR-026）
  • 品牌归运营商，代理商不得拥有
  • 机柜→设备 Device（ADR-021）
  • 主体 Entity不抽（无多执照场景）
一 · 关联二 · 泛化三 · 依赖

一、关联 — 谁指向谁

站点是全图的交汇点：品牌、代理商、场地方三条线在这里汇合，往下逐级继承归属，往右汇成一笔订单和两份分润。

高亮

二、泛化（继承）— 四处成立

空心三角指向父类型。四处都不是 Java 继承：设备靠注册表 + 策略，订单靠主表 + 扩展表，受益方与登录主体靠同一条链跑不同取值。

三、依赖 — 单向

实线是行为依赖，虚线是事件。场所层不知道交易层存在，交易层不知道资金层存在——只往下游发事件。
