# ADR-004 分账双模式

状态：已接受（2026-07-11）

## 背景
分成方（商户/代理）诉求不一：有的要求资金不过平台（合规/信任），有的无特约商户资质只能平台代结。

> 注：支付/收单委托 neargo nearpay（ADR-005），故「渠道分账」能力取决于 nearpay。分润**规则**归 powerbank，**执行/打款**优先复用 nearpay，与支付一并延后落地。

## 决策
分润**规则引擎在 powerbank**；分账**执行**做成**可配置双模式**，按「租户 + 分成方」维度选择：
- `CHANNEL_SPLIT` 渠道分账：**若 nearpay/PSP 支持 split settlement**，由 nearpay 直接分账到分成方账户。
- `LEDGER` 平台记账：powerbank 复式记账入分润账户 → 周期结算单 → 提现审核 → 经 nearpay 统一打款。**通用兜底，MENA 首期主用。**

统一约束：任何资金动作先记账后执行；日切三方对账（渠道账单 ↔ 支付单 ↔ 账务分录）。

## 备选与否决
- 仅官方分账：分成方必须有特约资质，覆盖不了长尾商户 → 否决。
- 仅平台记账：资金池合规风险、大客户不接受 → 否决。

## 影响
账务模块必须一期就有复式记账骨架（account/entry/voucher）；分润引擎输出统一「分润指令」，由模式路由执行。
