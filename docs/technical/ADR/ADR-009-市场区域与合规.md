# ADR-009 市场、区域与合规

状态：已接受（2026-07-11）

## 背景
powerbank 主要在**阿联酋（UAE）及其他中东（MENA）国家**运营，**同时支持少量国内用户经海外微信使用**。此前文档默认「中国市场、CNY、微信/支付宝为主」，与实际market不符，须纠正。

## 决策
1. **主市场 MENA，多区域**：默认区域 UAE，扩展至 KSA 等；复用 commons `region_id`（BaseEntity 自带）做区域隔离/数据驻留（Cell）。中国为**次要小众段**（海外微信中国用户）。
2. **默认币种 AED，多币种**：金额 `DECIMAL(18,2)` + `currency`，默认 `AED`（此前 `CNY` 作废）；按租户/区域配置。
3. **i18n：ar/en 双语 + RTL**（阿语一等公民），前后端全链路；用户可见字段双语（对齐 neargo `xxx`/`xxx_ar` 或 `xxx_i18n JSON`）。
4. **合规双轨**（对齐 neargo）：
   - **个人数据 PDPL**：C端手机/证件等落 `*_pii` 库 + 独立 KMS + 区域内驻留。
   - **资金 CBUAE**：trade 资金轨独立库/KMS/区域驻留。
5. **支付面向 MENA**（详见 [ADR-005](./ADR-005-C端载体与MENA支付.md)）：本地 PSP 收单为主，微信/支付宝降为 niche。
6. **强化 neargo 对齐**：neargo 本即 UAE/MENA 平台（AED/PDPL/CBUAE/ar-en-RTL/nearpay），powerbank 的区域/合规/i18n/支付可最大化复用 neargo 设计与（未来）nearpay 契约。

## 影响
- db-design 币种默认改 AED；关键用户可见字段加双语；区域驻留策略按 region。
- 前端全端 ar/en + RTL（见 [ADR-008](./ADR-008-前端技术栈.md)、tech-stack-frontend）。
- 免押从「芝麻/微信支付分」（中国专属）改为**银行卡预授权冻结**（通用），微信支付分仅小程序中国用户可选。
- 地图/推送按区域：中东 Google Maps + FCM/APNs；中国 高德 + 微信订阅消息。
