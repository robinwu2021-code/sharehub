# ADR-008 前端技术栈

状态：已接受（2026-07-11，含 MENA/App 优先修订）

## 背景
powerbank 四类前端：运营端（平台超管+租户）、C端（**App 优先，小程序次要**——中东以 App 为主，小程序仅服务少量海外微信中国用户）、运维 App、商户/代理端。用户要求运营端参考 ai-boss 框架并与 UnoCSS 对比。

## 现状调研
- `ai-boss/ops-web`：**Next.js 16 + React 19 + Tailwind CSS 4 + shadcn/ui**（radix-ui + cva + clsx + tailwind-merge + lucide + tw-animate-css；带禁任意字号/禁裸控件 lint，设计系统规整）。
- `ai-boss/boss-app`：Expo / React Native；`ai-boss/boss-flutter`：Flutter。
- `ai-nearboss/merchant-web`：React18+Vite（较旧）。

## 决策
1. **运营端 = 采用 ai-boss 栈**：**Next.js 16 + React 19 + Tailwind 4 + shadcn/ui**，与 ai-boss ops-web 一致（复用组件/设计系统/lint 规范/团队）。数据密集后台（设备/工单/财务表格）配 **TanStack Table** 自装企业级表格（shadcn 无开箱重表格）。图表 ECharts / Recharts，地图高德/Google Maps。
   - 否决 Ant Design 系：开箱表格快，但与 ai-boss 另起一套，一致性代价更大。
2. **样式统一 Tailwind 心智**（取代早前 UnoCSS 提案）：运营端 Tailwind 4（shadcn 依赖）；C端 uni-app 用 **UnoCSS + `preset-wind`（Tailwind 兼容类名）经 `unocss-applet`**——类名心智一致，各端用最适引擎。**shadcn/ui 只在运营端 Web**（依赖 Radix DOM，小程序/uni 无 DOM 不可用）。
3. **C端 = uni-app（Vue3 + TS），App 优先**：一套代码 App + 小程序，**App 为 P0 主目标**（uni-app App 端/uni-app x），小程序为次要（服务海外微信中国用户）。UI 库 wot-design-uni，状态 Pinia。
   - 否决 RN/Expo 与 Flutter：虽 App 原生度更好，但无法一套覆盖小程序；powerbank 仍需小程序（中国用户），uni-app 一套两端更省。
   - 否决 Taro：可一套两端，但 App 原生度与小程序生态均不及 uni-app。
4. **运维 App / 商户代理端 = uni-app** 复用 C端基座。

## 影响
- 运营端(React/Next/shadcn) 与 C端(Vue/uni) 语言分裂，接受（各自场景最优）。跨端统一发生在**地基**：TS 契约（powerbank-common-api→前端类型）、请求层封装（Result<T>/鉴权/幂等）、**Tailwind 兼容原子类心智**、设计 token。UI 组件层不强行统一。
- App 优先 → C端打包/发版以 App Store/Google Play 为主，小程序为次要构建目标。
