### ⚠️ 过程风险（已定因）
一个 agent 为判断类型错误是否既有，在**共享工作树里跑了 `git stash`**，当时 6 个 agent 并发写，
pop 冲突后它手工重放了两处别人的改动。文件级已核验无丢失（stash 117 文件与工作树取差集为空），
两个 dangling commit（`fcfd930`/`cecddcf8`）先别 gc。教训：给 agent 的任务书只禁了文件、**没禁 git 命令**；
后续批量改动应用 `isolation: "worktree"` 隔离。详见任务 #25。
