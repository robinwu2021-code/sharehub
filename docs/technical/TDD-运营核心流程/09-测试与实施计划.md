|---|---|---|---|---|

| **P2 站点状态** | `SiteService` 抽出 · 状态机 · 状态日志 · 开业清单 / 关闭门禁 · `SiteGoLiveListener` · tick · `SiteBrief` 扩字段 · 生命周期只读 | 站点列表 / 详情头 / 清单 · 生命周期漏斗 | M3 · M8（站点部分） | 03 §九 |
| **P3 设备与门禁** | 机柜状态机 · 门禁 · 试借还 · 保护动作 · 信号入口与字典 · `RentabilityGuard` 接入借出 · `PricingProbe` | 设备详情七页签 · 门禁 · 试借还 · 保护列表 | M4 | 04 §六 |

依赖外部的只有两处：COS 账号与桶（P0 的 COS 适配器冒烟，本地适配器不受影响）、支付接入（`PAYMENT_STATE_UNKNOWN` 出厂关闭）。

## 二、每批的完成定义

1. 迁移在测试库 `test_sharehub` 上正向执行通过（版本号取**合入时**的最新 + 1）；
2. 本批场景测试全绿；`backend` 全量 `mvn test` 中架构与词表卡口全绿（下表台账变化在同一提交内完成）；
3. ops-web：`npx vitest run` 全绿、`npm run check:drift` 全绿、棘轮基线不升；
4. 改 `globals.css` 的批次：清 `.next` 重启后 `curl` served CSS 核对 token（`CLAUDE.md` 坑 1）；
5. 更新 [实现状态总表](../实现状态总表.md) 与 [运营核心流程-功能矩阵](../../requirements/运营核心流程-功能矩阵.md) 的现状列；
6. 提交只用显式路径；提交前 `git status --porcelain -- <文件>` 与 `git diff` 逐文件确认没有别的会话的在途改动。

## 四、测试基建

| 项 | 做法 |
|---|---|
| 时间推进 | 后端注入 `java.time.Clock`（`@Bean Clock`，测试覆盖为可调时钟）；引擎、tick、影响评估一律取 `clock`，不直接 `LocalDateTime.now()` |
| 设备信号 | 测试经 `POST /internal/events/device`（`X-Internal-Token`）注入，与生产同一入口 |
| 测试库有状态 | 不假设第一页有自己的数据：用 `findInPages`；每个用例自建站点 / 机柜（唯一名后缀） |
| 并发用例 | `CompletableFuture` 两路同时调，断言唯一约束结果 |
| 文件 | `sharehub.storage.type=local`，根目录用 JUnit `@TempDir` |
| 前端 | mock 层用例覆盖状态机与联动；页面用例只测交互分支（禁用态、确认框、必填） |

## 五、风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| Outbox 进程内重投缺陷未修 | 联动事件丢失 | 07 §3.1 每个关键事件都有 tick 兜底；修复任务已单独立项 |
| 多会话并行，迁移版本号撞车 | 乱序执行 | 合入前 rebase 并重编号；迁移互不依赖版本号（全部 `IF NOT EXISTS`） |
| `SiteBrief` / `CabinetBrief` 追加字段 | 现有构造点位置参数错位（全是 String，编译器抓不到） | 只追加在末尾；每个构造点逐一补参并在评审中核对 |
| 告警 tick 每分钟扫全部站点 | 规模上来后变慢 | 每批 200 站点、每站一个短事务；`availabilityBySites` 一条聚合 SQL；站点数 > 2000 时改为按区域分片（L2） |
| 生成列唯一键（`open_key`） | 数据库兼容 | 生产与测试同为 MariaDB 12；迁移头部注明，若换库需改为应用层锁 |
| 前端先于后端完成 | 真实后端模式下点了 404 | `backend-ready` 门禁挡住未就绪动作 |

## 六、评审要点（开工前请确认）

1. 章节划分与分批顺序（§一）；
2. 合同表**不改**继承 `BaseEntity`、只加列（02 §三）；
3. 站点状态日志**新建表**而非复用生命周期日志（03 §二）；
4. 信号字典与保护动作归**设备域 core**，业务告警只订阅与申请（04 · 05）；
5. 告警唯一性用**生成列唯一键**（05 §二）；
6. 工单关联告警的读取放 `portal` 编排层，保持 `wo` 不依赖 `alarm`（06 §五）；
7. 新增 3 个权限码（合同 submit / audit / terminate）随端点同一提交登记（02 §五）；告警细码由在途工作提供（05 §九）。
