## 一、读法

| 列 | 含义 |
|---|---|
| 编码 | `OM<一级>-<序号>`，例如 `OM04-02` = 销售管理第 2 项 |
| 功能要点 | 该页面要做到什么；**加粗**的是相对现状需要补的部分 |
| 权限码 | 页面的读权限码；写操作的细分码见 [功能权限清单](./功能权限清单.md)。`†` = 代码在用、真源表未登记（既有缺口）；`＊` = 本文拟新增，**须先登记进真源表再用** |
| 默认角色 | 由 `RolePerms.java` 按权限码推算（拟新增的码为建议值）：管 = 管理员 · 运 = 运营 · 客 = 客服 · 财 = 财务 · BD = 拓展 / 销售 · 读 = 管理层只读 · 商 = 商家 |
| 承接需求 | 运营方原始需求编号（省略 `RQ-` 前缀）；`—` 表示原文未要求、为项目既有能力 |
| 现有菜单 | 今天 `nav.ts` 里的位置；`—` 表示没有 |
| 状态 | ✅ 现有（不用改）· ◐ 改造（已有，需按要点补齐）· 🆕 新增 · ⏸ 预留 |
