## 三 动作授权与复核规则

下列为建议授权，不代表已实现。各功能表的“建议可见”只授予查看资格，不能推出写权限；执行动作必须同时满足本表、业务权限码及数据范围。ADMIN 的现有通配权限也不能替代申请人与复核人分离。

| 动作类别 | 发起／执行角色 | 复核与限制 |
|---|---|---|
| 收货、质检、入库、出库、调拨、盘点录入 | 仓；运仅执行明确分配的现场签收和撤机任务 | 质检、库存操作分别判权；建议逐步收回 OPS 的 inventory:*，保留明确动作 |
| 仓库、供应商、物料档案维护 | 管，另行授权的仓 | 当前 WAREHOUSE 未持 inventory:warehouse，不默认为已授权；成本字段财务可见 |
| 盘点调整、反向单、差异结案 | 仓发起；另一名具备授权的仓储复核人审核 | 涉价值调整由财参与；同一角色可以有多人，禁止同一人自审；待拆分动作权限 |
| 库存引擎切换与远程恢复 | 管执行；仓／财参与对账 | 稳定幂等键、无未处理在途操作、完整审计；业务重试按领域权限授权 |
| 设备命令、OTA、上线撤机 | 运；客仅按工单授权有限命令 | 危险命令和批量动作独立授权；仓不因能查台账就能下发指令 |
| 商家入驻与合同 | BD代建／提交；管或授权运营复核；财会签财务条款 | 商家账号、资产归属、分润变更分别判权；同人不得提交又复核 |
| 收费方案与分润规则 | 财或另行授权BD提交；另一名授权人员复核 | 生效时间、版本、试算结果留痕；BD默认不直接发布财务规则 |
| 投诉退款与订单干预 | 客申请、处理；财审批和退款执行 | 审批与执行独立动作；执行幂等；不得以投诉已解决替代真实退款 |
| 结算确认、付款、手工凭证和调整 | 财发起；另一名财复核；另行授权财执行付款 | 同人不得自审；银行账户变更需独立复核；未具备双人条件不得绕过 |
| 客户资料、联系人、风险、报修 | 客按职责处理；商仅改本商家联系人及报修 | 后端脱敏、租户／商家范围强制；钱包调整和免押策略另授权 |
| 导出与下载 | 具有对应导出权限的角色 | 查看不自动允许导出；复用查询范围，审计下载、脱敏及链接有效期 |
| 系统安全与恢复 | 管；财配置税务与银行等专属项 | 生产恢复及密钥修改独立权限、操作记录、必要时双人复核 |

5. 保留完整原目标154项并列出当前新增细分入口；本文件统计的是功能记录，141是原导航入口数，均不作为完成率。

8. SERVICE依赖、OpsKit接入和占位实现必须明确展示；第三方未接通的功能不得以成功状态替代真实结果。
