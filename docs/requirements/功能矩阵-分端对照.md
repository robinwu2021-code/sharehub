## 0. 端的定义与边界

| 端 | 定义 | 备注 |
|----|------|------|
| **运营端** | Web 管理后台。因 SaaS 架构分两级：**平台超管后台**（SaaS 运营方）+ **租户运营后台**（各品牌方） | 两级共用一套前端框架，按角色/租户渲染 |
| **服务端** | 全部后端服务能力：对上支撑各端，对下承接硬件供应商与支付渠道 | 按领域服务划分 |
| **C端** | 终端消费者：**App（主力，中东）** + 微信小程序（次要，海外中国用户），本文逐项对照两载体差异 | uni-app 一套码，App 优先 |

运维 App、商户端、代理端见总矩阵，本文不展开。

优先级沿用：P0 = MVP · P1 = 规模化 · P2 = 增强。

## 1. 运营端功能矩阵

## 2. 服务端功能矩阵

| 服务域 | 核心能力 | 支撑对象 | 优先级 |
|--------|---------|---------|--------|
| **设备接入网关** | TCP/MQTT 长连接、HTTP/Webhook 回调双栈；供应商 driver 插件化；统一指令模型；指令队列/超时重试/幂等；验签与密钥；报文日志 | 硬件供应商 | P0 |
| 设备服务 | 台账、设备影子（在线/仓位/电量）、生命周期状态机、设备-租户/点位归属、OTA 任务管理 | 运营端/运维/C端 | P0 |
| 点位商户服务 | POI、商户档案、合同、可借可还库存计算 | 运营端/C端 | P0 |
| 订单服务 | 租借订单状态机、超时关单调度、异常订单处理、订单-设备事件对账 | C端/运营端 | P0 |
| 计费服务 | 计费引擎（时长/封顶/免费时长/分时段）、价格模板、按点位取价 | 订单/运营端 | P0 |
| **支付服务** | 聚合支付网关、PSP adapter（Network Intl/Telr/PayTabs/Checkout；卡/Apple/Google Pay）、预授权 auth/capture/void（免押）、回调验签幂等、退款、对账；微信/支付宝为 niche | C端/财务 | P0 |
| 账务分润服务 | 平台内记账（复式）、分润规则引擎、**官方分账 adapter + 记账双模式**、结算单、提现 | 财务/商户/代理 | P0（分账执行 P1） |
| 用户服务 | C端账户与授权登录、实名、信用分/黑名单、会员、钱包 | C端 | P0（会员钱包 P1） |
| 营销服务 | 优惠券（发放/核销/风控）、活动、权益计算 | C端/运营端 | P1 |
| 工单服务 | 工单状态机、派单策略引擎、告警→自动开单联动、SLA 计时 | 运营端/运维App | P0 |
| 消息服务 | 模板管理、多通道分发（短信/订阅消息/Push/站内/企微） | 全端 | P0 |
| **租户服务** | 租户元数据、数据隔离策略执行、租户级配置中心（支付/计费/品牌）、配额 | 全局 | P0 |
| 认证权限服务 | 员工账号、RBAC、数据权限(区域/租户/点位)、SSO、审计日志 | 运营端 | P0 |
| 数据服务 | 埋点采集、指标聚合、报表 API、大屏推送 | 运营端 | P1 |
| 开放平台 | OpenAPI、AppKey/签名、限流、文档 | 第三方 | P1 |
| 基础设施 | 定时任务调度、监控告警(APM/日志/链路)、配置中心、文件存储 | 全局 | P0 |

## 3. C端功能矩阵（微信小程序 vs App）

图例：✓ 支持 · ◐ 形态/能力受限 · — 不提供

| 功能 | 说明 | 小程序 | App | 优先级 |
|------|------|:------:|:---:|--------|
| 登录授权 | 小程序：微信一键授权+手机号快捷；App：手机号验证码 + 微信/Apple 三方登录 | ✓ | ✓ | P0 |
| 扫码借出 | 扫机柜二维码 → 确认页 → 弹出 | ✓ | ✓ | P0 |
| 附近网点 | 地图找机柜、可借/可还数量、导航 | ✓ | ✓ | P0 |
| 免押租借 | **银行卡预授权冻结（App 主）**；微信支付分仅小程序中国用户 | ◐ 小程序走支付分 | ✓ 卡预授权 | P0 |
| 支付收银台 | 小程序 JSAPI 支付；App 微信/支付宝 SDK 支付 | ✓ | ✓ | P0 |
| 进行中订单 | 计时计费实时展示、归还指引 | ✓ | ✓ | P0 |
| 归还确认 | 归还成功通知、费用结算展示 | ✓ | ✓ | P0 |
| 我的订单/账单 | 历史订单、费用明细、押金状态 | ✓ | ✓ | P0 |
| 自助报障 | 未弹出/无法归还/多扣费自助流程 + 客服入口 | ✓ | ✓ | P0 |
| 押金管理 | 退押金申请、押金状态 | ✓ | ✓ | P0 |
| 消息触达 | 小程序订阅消息（模板受限、需订阅）；App Push（自主可控） | ◐ | ✓ | P0 |
| 优惠券 | 领券、用券、券包 | ✓ | ✓ | P1 |
| 会员/次卡 | 包月、次卡、权益 | ✓ | ✓ | P1 |
| 钱包 | 余额、赠金 | ✓ | ✓ | P1 |
| 发票 | 开票申请、抬头管理 | ✓ | ✓ | P1 |
| 蓝牙近场借还 | 弱网/无网场景蓝牙直连柜机 | ◐ 小程序蓝牙可行但体验弱 | ✓ | P2 |
| 邀请裂变 | 分享有礼、拉新 | ✓ | ◐ 分享回微信链路长 | P2 |
| 注销/隐私合规 | 账号注销、隐私协议、个保法合规 | ✓ | ✓ | P0 |

**载体策略（修订 ADR-008，MENA/App 优先）**：
1. **App P0 先行** —— 中东主战场是 App Store/Google Play；uni-app 一套码，App 为主目标，卡/Apple Pay/Google Pay 收银，卡预授权免押。
2. **微信小程序 P1** —— 服务海外微信中国用户，加 `MP-WEIXIN` 条件编译分支（微信支付/支付分）。
3. **支付宝小程序 按需** —— 中国用户量起来再加。

## 4. 三端对照矩阵（业务能力 × 端）

| 业务能力 | C端（呈现） | 服务端（职责） | 运营端（管控） |
|---------|------------|---------------|---------------|
| 借出 | 扫码 → 确认页 → 等待弹出 | 设备可用校验 → 创单 → 免押/预授权 → 网关下发弹出指令 | 订单实时可见；弹出失败告警 |
| 计费 | 费用实时展示、封顶提示 | 计费引擎按点位价格模板计价 | 定价模板/分时段策略配置 |
| 归还 | 网点指引 → 归还成功页 | 归还事件 → 停止计费 → 结单 → 请款/解冻 | 异地归还、异常归还监控处理 |
| 免押/支付 | 免押授权、收银台 | 渠道路由、auth/capture、回调幂等、补单 | 渠道商户号配置（按租户）、对账差错 |
| 退款/客诉 | 自助报障、退款申请 | 退款执行、原路退回、状态跟踪 | 客服受理、审批、补偿免单 |
| 设备可用性 | 地图可借/可还数 | 心跳/影子、库存实时计算 | 状态监控、远程控制、离线告警 |
| 故障运维 | 报障入口 | 告警规则 → 自动开单 → 派单策略 | 工单看板、SLA、审核关单（运维App执行） |
| 营销 | 领券用券、买会员 | 券核销、权益计算、防刷 | 券/活动/推送配置 |
| 资金分配 | —（无感知） | 分润引擎、官方分账/记账双模式、结算 | 分润规则配置、结算审核、提现打款 |
| 数据 | — | 埋点采集、指标聚合 | 看板、报表、大屏 |
| 租户隔离 | 品牌小程序（各租户独立） | 全链路租户上下文、数据隔离 | 平台超管跨租户；租户后台只见自己 |

## 5. 借还主流程三端对照（时序）

| # | C端（用户动作） | 服务端（处理） | 运营端（可见/介入） |
|---|----------------|---------------|-------------------|
| 1 | 扫机柜码 | 解析 SN → 租户/设备/仓位可用性校验 → 返回确认页与价格 | — |
| 2 | 确认借出 + 免押授权 | 创建订单 → 支付分/芝麻/预授权下单 | 订单状态「已创建」 |
| 3 | 等待弹出 | 网关经 driver 下发弹出指令 → 设备事件确认 → 订单「进行中」 | 弹出失败 → 告警 → 自动工单 |
| 4 | 使用中，进行中页计时 | 计费引擎计时、心跳跟踪充电宝 | 订单「进行中」监控 |
| 5 | 归还入仓（任意网点） | 归还事件 → 停止计费 → 结单 → 请款/退押 | 订单「已完成」 |
| 6 | 查看账单、开票、领券 | 分润记账（或官方分账）→ 消息触达 | 分润明细、对账、报表 |
| 异常 | 自助报障 | 异常订单标记、退款流程 | 客服介入、干预、补偿 |
