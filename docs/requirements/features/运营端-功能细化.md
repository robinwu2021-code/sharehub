# 运营端 · 功能细化

> 下钻自[分端矩阵 §1](../功能矩阵-分端对照.md)。层级：平台=超管后台 / 租户=租户后台 / 双=两级都有（数据范围不同）。
> 「实现」= [ops-web](../../../ops-web) 落地状态（✅已建 mock · ◐部分 · ⬜待建）。
> **定位（ADR-011）：单运营方自营为主**。所有「平台」层功能点（下表标 🔒）= 多租户口子的管理面，**MVP 后置为 P1+**；MVP 运营重心是主租户日常经营（工作台/设备/订单/工单/财务/点位/用户/员工）。运营端两级后台 MVP 收敛为**一套主租户运营后台**。
