## 载体与端差异要点
1. **App P0 优先**：App Store/Google Play 是中东主渠道；卡/Apple Pay/Google Pay 收银、卡预授权免押、Push 自主可控、蓝牙近场体验好。
2. **小程序 P1**：服务海外微信中国用户；`MP-WEIXIN` 条件编译分支（微信支付/支付分/订阅消息）；能力受限项以 ◐ 标注。
3. **一套 uni-app 代码**：登录/支付/免押/推送用条件编译隔离，业务与 UI 共用。
4. **合规**：ar/en + RTL；PDPL（授权/注销/导出）；免押以卡预授权为通用主路径。
