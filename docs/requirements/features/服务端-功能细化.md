# 服务端 · 功能细化

> 下钻自[分端矩阵 §2](../功能矩阵-分端对照.md)。按领域服务列能力点，含：职责与关键接口/事件、规则/一致性/边界、验收。
> 部署：业务域为 app-modulith，access-gateway 独立进程（架构 §4）。库 3 个（core/pii/auth）。

---

## 1. 设备接入网关（access-gateway · P0）
> 详见 [TDD-access-gateway](../../technical/TDD-access-gateway.md)。

| 编号 | 能力点 | 职责与接口/事件 | 规则/一致性/边界 | 验收 |
|------|--------|----------------|-----------------|------|
| SVR-GW-01 | 三栈南向接入 | Netty TCP / EMQX MQTT / HTTP Webhook 三连接层 → `DeviceDriver` SPI | 每供应商一 driver；新增不改业务、热加载 | 三型各通一家；新增 driver 零业务改动 |
| SVR-GW-02 | 统一指令下发 | `dispatch(DeviceCommand)`→queue→driver.encode/invoke；8 指令 | `commandId` 幂等(Redis SETNX)；超时重试 N；终态失败回调 | 重复不重复弹出；失败有回调 |
| SVR-GW-03 | 统一事件上行 | driver.decode/parseWebhook→`DeviceEvent`→`DomainEventPublisher`；8 事件 | 业务键幂等去重；乱序/重复守卫 | 事件解析准确；重复不重复计 |
| SVR-GW-04 | 会话管理/在线态 | `SessionManager` SN↔连接，Redis `sn→实例`；心跳判在线 | 90s 超时判离线；多实例转发；宕机重连自愈 | 跨实例指令可达；离线判定准 |
| SVR-GW-05 | 验签/密钥/报文留痕 | 回调验签；密钥 KMS；上下行报文脱敏落 `gw_message_log` | 验签失败拒绝；报文 TTL/脱敏 | 非法回调拒绝；报文可回放 |
| SVR-GW-06 | OTA 下发通道 | 承接 ops 的 OTA 任务下发+结果回收 | 仅通道，版本账本在 ops | 下发/回报闭环 |
