## 一、角色

| 角色码 | 名称 | 在设备管理里的定位 | 数据范围 | 状态 |
|---|---|---|---|---|
| `WAREHOUSE` | **仓管** | 到货登记、质检、入库、发货、盘点录入 | 按**区域**（仓库所在区域） | 🆕 建议新建（B §九 P1） |
| `OPS` | 运维 | 现场：签收、装机、上线、远控、维修、撤机 | 按**区域 / 点位** | 现有 |
| `ADMIN` | 运营管理员（主管） | 全部；出库调整 / 撤回、盘点复核、仓库与库存设置 | 全域 | 现有（`*`） |
| `FINANCE` | 财务 | 库存与报表只读（对账、资产） | 全域 | 现有 |
| `CS` | 客服 | 查设备状态、远程弹出、报障开单 | 全域只读 + 客服动作 | 现有 |
| `BD` | 拓展 | 不参与设备管理 | 按区域 | 现有 |
| `VIEWER` | 只读分析 | 设备与库存只读 | 全域 | 现有 |
| `AGENT` | 商家（商家门户） | 只看自己的设备与「待交付设备」 | 限自己 `agent_no` | 现有 |

## 九、裁决记录（2026-10-29 · 按建议定）

| # | 事项 | 结论 |
|---|---|---|
| Q1 | **运维是否保留库存写权限**（现持 `device:inventory:*`，会自动拿到发货、调整、复核、仓库管理） | **收回**到「读 + 签收 + 质检」；发货、盘点录入交给仓管，调整、复核、仓库交给管理员。资产差异处置拆出单独的码（`device:inventory:diff`，待登记）留给运维。过渡期仓管角色上线前，运维暂留现有 `device:inventory:*` |
| Q2 | 质检单独建码 `device:qc:inspect` | **建**：否则仓管为了质检要拿 `device:cabinet:update`，等于能上线、改设备 |
| Q3 | 是否新建「仓管」角色 | **建**（同 B §九 P1）；人少时一人可兼运维与仓管两个角色 |
| Q4 | 财务看库存 | **给只读**（库存余额、单据、总览、报表），用于资产对账 |
| Q5 | 库存报表用 `report:inventory:*` 还是 `device:inventory:read` | **`report:inventory:*`**：跟数据报表一级菜单的授权体系一致，财务 / 拓展 / 只读经 `report:*` 自动可见 |
