# 功能权限清单（RBAC SSOT）

> 状态：草稿（待确认）· 创建 2026-07-11
> 定位（[ADR-011](../technical/ADR/ADR-011-单运营方为主多租户为口子.md)）：单运营方内部角色。
> 用途：前端按钮级鉴权 + 后端 `@PreAuthorize` 的**唯一权限码来源**。对齐 [功能清单-单运营方运营系统](./功能清单-单运营方运营系统.md)。

---

## 一、权限码规范
`<模块>:<资源>:<动作>`，小写点分。
- **通用动作**：`read` 查 · `create` 增 · `update` 改 · `delete` 删 · `export` 导出 · `import` 导入。
- **专用动作**：如 `command`(下发指令) · `dispatch`(派单) · `intervene`(干预) · `refund`(退款) · `audit`(审核) · `config`(配置) · `assign`(分配) 等，见各域。
- 通配：`<模块>:*` = 该模块全部；`*` = 超管全部。

## 二、角色集（单运营方内部）
| 角色码 | 名称 | 职责范围 | 数据权限 |
|--------|------|---------|---------|
| `ADMIN` | 运营管理员 | 全部（`*`）| 全域 |
| `OPS` | 运维 | 设备 / 工单 / 库存 / OTA | 按**区域/点位**限定 |
| `CS` | 客服 | 订单干预 / 退款申请 / 用户风控 / 报障受理 | 全域只读 + 客服动作 |
| `FINANCE` | 财务 | 财务 / 分润 / 结算 / 提现 / 对账 / 发票 | 全域财务 |
| `BD` | 拓展 | 点位 / 场地方 / 合同 / CRM | 按**区域**限定 |
| `AGENT` | 代理商（代理端）| 自己设备/订单/收益 只读 + 提现申请 + 报修 | **限定自己 `agent_no`** |
| `VIEWER` | 只读分析 | 看板 / 列表 / 报表 只读 | 全域只读 |
| 🔒 `PLATFORM_ADMIN` | 平台超管（口子）| 多租户管理（§15）| 跨租户 |

> `AGENT` 是运营方体内的受限外部伙伴（[ADR-012](../technical/ADR/ADR-012-代理商模型.md)），**数据范围强制 = 自己 `agent_no`**，只见/操作自己归属的设备/点位/订单/收益。下表凡代理有的权限均隐含此数据范围。

> **两类权限**：**功能权限**（本清单，能否执行某操作）+ **数据权限**（能看/操作哪些区域/点位/租户的数据）。数据权限维度：`ALL` / `REGION` / `LOCATION` / `SELF`（自己经手）。OPS/BD 默认按区域或点位收敛（见各角色）。
> 下表 ✓=有该权限。`ADMIN` 拥有全部，表中省略其列（默认 ✓）。

## 三、落地约定
- **后端**：`@PreAuthorize("hasAuthority('order:refund:audit')")`；数据权限经 `TenantContext`+数据范围拦截（区域/点位）。权限码集中在 `powerbank-common-api` 常量。
- **前端 ops-web**：菜单/按钮读权限码（`can('device:command:send')`）；`lib/permissions.ts` 由本清单生成角色→权限映射。
- **角色-权限映射存库**：`iam_role` / `iam_role_perm`（可后台维护自定义角色，ADMIN/内置角色只读）。
- **审计**：所有 `create/update/delete/*audit*/*intervene*/*refund*/command` 写 `OperateLog`。
