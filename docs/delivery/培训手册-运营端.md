# 运营端培训手册（运营方原始需求相关功能）

日期：2026-10-29　·　对应 DLV-11　·　面向：运营管理员、财务、客服

> 只覆盖本期按运营方原始需求新增或改动的功能。基础操作（登录、站点、设备、订单查看）见各页面自带的说明。

## 一、管理员：先把「待拍板」的取值定下来

**系统设置 › 规则与参数 › 系统参数**，筛选选「只看待拍板」。每一项都写明了：
- **改了会影响什么**，例如「只影响之后的订单」；
- 可选值是什么、范围多少；
- 缺省值。所有缺省都等于现在的行为，不改也能运行。

| 分组 | 参数 | 说明 |
|---|---|---|
| 计费 | 服务费金额 / 是否计 VAT / 是否进分成基数 / 谁付 | 金额 0 = 不收；原文举例 0.60 / 0.90 |
| 计费 | 超时扣款模型 | 累计触顶买断（现行）/ 到时限发起最高收费 |
| 计费 | 计费周期取整缺省 | 不足一个周期：进一 / 舍去 / 过半进一；每个计费方案也能单独选 |
| 发票 | C 端税务发票开关 / 开票时点 / 开票主体国家 | 打开前先在「税率与发票」里填好开票主体的法定名称、地址、TRN |
| 发票 | 商家自开票 | 只对商家档案里填了 VAT 税号的商家生效 |
| 财务 | 分成比例上下限 | 原文 15%–50%；缺省 0 / 1 表示不约束 |
| 财务 | 分润舍入 / 小数位、分成基数口径、单均固定额 | — |
| 财务 | 补偿 / 免单审批线、手工凭证审批线 | 留空 = 不需要审批 |
| 合同 | 到期提醒天数 | 原文「2 个月」 |

改错时，系统会直接拒绝保存并说明原因，不会出现「显示已保存、其实没生效」。每一次改动都在操作审计里留有改前改后。

## 二、财务

1. **租赁发票**（财务 › 发票 › 租赁发票（C 端））
   - 发票是系统自动开的：开关打开后，每笔收款开一张，退款批准后自动开贷项通知单冲红。
   - 状态是「主体缺项未开」时，说明开票主体缺少 TRN 等信息。去「税率与发票」补齐后，在这里点「重试开票」。
   - 可以下载单张 PDF、导出登记表（Excel / PDF）、按开票期间批量下载 PDF 压缩包（一次最多 500 张）。
2. **商家自开票**（同一页的「商家自开票」）：商家提现到账后自动生成。商家后来才补录税号的，按提现单号点「补出」。
3. **跨期应付**（结算 › 结算单，页面下方）：按商家 × 月份列出应得、已出结算单、已付、未付，默认「只看未付」。
4. **审批**
   - 补偿 / 免单：订单 › 退款记录 页面上方的「补偿 / 免单审批」。
   - 手工凭证：财务 › 账务分录 页面上方的「手工凭证审批」。
   - **不能批自己提交的**；驳回必须写原因。
   - 批准时如果订单状态已经变了（例如已关单），会显示「批准但执行失败」，并写明原因。这时请申请人按现状重新提交。
5. **导出**：报表、订单、发票都由后端导出全量（不再只是当前页）。PDF 里的中文需要运维配置字体，见上线检查清单。

## 三、客服

- **补偿 / 免单**：金额达到审批线时，提交后提示「已提交财务审批」，财务批准后才生效。没达到的仍然即时生效。
- **订单列表**可按借出日期、商家、站点、机柜号筛选。进行中的订单显示实时时长、已累计费用、封顶金额。

## 四、商家（商家门户）

- **提现记录**页面下方是「我的自开票」，可以下载 PDF。
- 商家资料里的 VAT 税号、营业执照号由运营代为录入。有税号的商家才会收到自开票。
