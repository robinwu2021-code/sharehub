## 需要运营方确认

1. **主机、COS、证书与 ai-shop 共用**：费用怎么分摊，以及将来是否拆开独立部署（拆分会影响主机与带宽费用）。
2. **支付通道与短信服务商**的合同主体、费率：服务费 C09、支付手续费是否计入分成基数（C07）都和这里有关。
3. **Google Maps API Key** 用谁的账号：用开发方的账号，交接时要换成运营方自己的。
