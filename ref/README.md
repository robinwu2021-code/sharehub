（最后一次提交 2026-07-14，之后再没动过），而 `main` 的文档里一直写着
「来源：`ref/充電寶專案_V4(1).pdf`」—— 一条指向不存在文件的引用。

发现经过：清理分支时本打算删掉那个看似废弃的分支，核对「它有没有 main 里没有的东西」，
才发现 18 个文件里最要紧的就是这两份原件。**教训：删分支前先比对文件集合，
不要只看提交标题判断是否已被取代。**
