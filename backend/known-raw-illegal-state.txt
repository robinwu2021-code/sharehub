# 裸 IllegalStateException 台账 —— 只准变短，且**每次变化都要改数字**（在 review 里显形）。
#
# 由 BizRejectionNotRawIllegalStateTest 卡住：格式 `类名 处数`，按类**精确相等**比对。
# 精确相等而不是「不超过」：同一个类里删一处又加一处会互相抵消，那样棘轮就是摆设。
#
# ───────────────────────────────────────────────────────────────
# 为什么这些**该**留在 500
#
# 业务拒绝（调用方换个做法就能成功、不需要任何人介入）已在 2026-09-25 全部改成
# `ServerException.of(ErrorCode.CONFLICT, …)` → HTTP 409 + 原话。方案见
# docs/technical/待办-业务拒绝的状态码.md。
#
# 下面这些不是业务拒绝，**一刀切改成 4xx 会比现在更糟** —— 它们需要人介入，
# 而 4xx 既不触发告警也不再记录堆栈，等于把一个真故障藏起来。
